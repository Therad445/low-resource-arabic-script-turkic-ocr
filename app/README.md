# Streamlit demo

Минимальный демо-интерфейс для OCR post-correction.

## Что делает интерфейс

Интерфейс демонстрирует постановку:

```text
OCR/noisy text → corrected text
```

Пользователь вставляет OCR-текст или выбирает один из сохранённых примеров, после чего приложение показывает результат посткоррекции.

## Запуск

```bash
streamlit run app/streamlit_demo.py
```

После запуска Streamlit покажет локальную ссылку, обычно:

```text
http://localhost:8501
```

## Режим без локальной модели

Большие checkpoint-файлы не хранятся в репозитории. Поэтому, если локальная fine-tuned модель не найдена, приложение запускается в fallback-режиме.

В fallback-режиме интерфейс:

- загружает сохранённые примеры из экспериментальных CSV;
- показывает noisy / prediction / clean;
- не заявляет полноценную нейросетевую коррекцию;
- явно предупреждает, что модель не загружена.

## Подключение локальной модели

Если локальный checkpoint доступен, можно передать путь через переменную окружения:

```bash
POSTCORRECTION_MODEL_DIR=/path/to/local/byt5_checkpoint streamlit run app/streamlit_demo.py
```

Также путь можно указать прямо в боковой панели интерфейса.

## Ограничение

Интерфейс является исследовательским демо к курсовой работе. Он не является production OCR-системой.

Основной вывод работы сохраняется: модель хорошо проверяется на синтетическом benchmark, но для реального архивного OCR требуется адаптация на настоящих OCR/reference парах.
