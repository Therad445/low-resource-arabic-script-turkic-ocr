# NLP Final Project Notes

This directory contains compact supporting materials for the NLP-course final project.

## Files

- `project_summary.md` — short description of the task, contribution, claim and limitations.
- `submission_checklist.md` — checklist for final submission readiness.
- `derived_split_statistics.csv` — split statistics derived from processed CSV files.
- `byt5_examples_sample.md` — sample ByT5 predictions.
- `best_examples_sample.md` — examples where ByT5 improves the input most strongly.
- `worst_examples_sample.md` — examples where ByT5 performs worse than the noisy input.

The main report is stored in:

```text
report/final_report.pdf
```

The project landing page is:

```text
NLP_FINAL_PROJECT.md
```
