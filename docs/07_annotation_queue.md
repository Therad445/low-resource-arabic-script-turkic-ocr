## Rules for moving items
- Move document to **Ready for pilot annotation** only after:
  - source provenance is known,
  - rights note is recorded,
  - scan quality is acceptable,
  - layout is not too complex for printed line-level OCR.
- Move document to **Rejected** only with a written reason in `data/metadata/rejected_documents.csv`.
